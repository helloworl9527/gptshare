    常见问题

    出现「model not found」怎么办？

    现在 OpenAI 增加了时区的检测，假如浏览器时区和梯子时区不一致会出现 model not found。

    浏览器时区设置教程

    1. 下载并安装插件：更改 Google Chrome™ 的时区（Change Timezone）。
    2. 打开插件设置，勾选「根据 IP 地址自动更新时区」（Automatically update timezone based on my IP address），然后点击「Save」保存。不要勾选「随机时区」（Pick a random time zone）。
    3. 刷新 ChatGPT 页面后重试；如果切换了代理 / VPN 节点，请重新检查并保存时区设置。
