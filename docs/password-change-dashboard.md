# 统一后台密码处理提醒

生产后台由根目录 `web/` 构建为 `internal/unifiedui/static/`，通过 `/admin/` 提供。
`allocation-service/web/` 是旧版独立前端，不是统一后台的构建入口。

运营总览独立展示“待更改密码”面板，查询失败不会阻断容量概览。页面“刷新数据”
同时刷新容量和密码清单；面板也支持独立刷新、错误重试和无待处理账号提示。

## 现有后端筛选规则

- 卡密已到期，按该卡密最近一次分配关联账号。
- 账号未归档，账号订阅剩余时间严格超过 3 天。
- 未标记处理，或标记后又有卡密到期。
- 此清单不是“近 72 小时过期卡密”清单，不套用其时间窗口，也不列出所有历史分配账号。

接口：`GET /api/admin/dashboard/password-change-due`。
仅返回提醒所需的账号、时间和数量，不查询密码、2FA 或令牌。

## 操作含义

管理员应先手动修改账号密码、检查已登录设备，并将新密码同步到账号池凭据；
如有其他有效卡密，要注意其他用户。点击“标记已更改密码”后需二次确认。

`POST /api/admin/dashboard/password-change-due/:id/clear` 通过统一管理员会话、
Origin 和 CSRF 校验，保存处理时间和审计记录。前端仅在成功后移除对应账号；
失败保留提醒并允许重试，提交期间禁用重复操作。

**标记不会实际更改密码，不会更新账号池密码，不会登出设备。**
之后若有卡密再次到期，后端规则会重新显示提醒。

接入不恢复其他隐藏面板，不改变卡密延期、账号分配或自动下线规则，无新增数据库迁移。
